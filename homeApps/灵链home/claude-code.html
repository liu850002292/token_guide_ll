Claude Code 接入灵链云：国内直连配置教程

Claude Code 是 Anthropic 推出的 AI 编程终端工具，能在命令行里直接读代码、改文件、跑测试。 对国内开发者来说，最大的门槛是网络与支付。本教程教你 3 分钟把 Claude Code 接到灵链云 API 中转站， 无需科学上网、无需外币卡，支付宝微信即可充值。

接入前后对比：
  • 接入前：需要海外网络与官方 Anthropic 账号、绑定外币卡，国内直连经常超时。
  • 接入后：只需把 ANTHROPIC_BASE_URL 指向灵链云，填入灵链云发的 API Key 即可运行。
  • 全程只改配置，不改代码。支持按量计费、用量透明、随时在控制台查看 Token 消耗。

一、接入前提

开始前请确认你已具备以下条件：

  • 已安装 Claude Code（支持 npm 安装与原生安装两种方式）；
  • 有一个可用的 灵链云账号，并已创建 API Key、账户内有余额；
  • 终端可正常访问 https://llapi.org/v1（国内网络直连即可）。

如果还没有账号，先花 30 秒在 灵链云注册页 完成注册，新用户注册即送体验额度。

二、第一步：注册灵链云并创建 API Key

2.1 注册与充值

打开 llapi.org/register 完成注册，登录后在「会员中心」充值。 灵链云支持 支付宝与微信支付，最低小额即可开始，用多少充多少即可，无需一次大额囤余额。

2.2 创建 API Key

进入控制台 →「API Key」→ 新建密钥。密钥形如 sk-xxxxxxxx，创建后请立即复制保存（仅显示一次）。

三、第二步：配置 Claude Code 环境变量

Claude Code 通过 ANTHROPIC_BASE_URL 指定网关地址、ANTHROPIC_AUTH_TOKEN 指定密钥。 推荐写入 Claude Code 的 settings.json，这样对所有项目生效。

编辑 ~/.claude/settings.json（Windows 为 %USERPROFILE%\.claude\settings.json），加入 env 字段：

{
  // 灵链云 Claude Code 兼容接入配置
  "env": {
    "ANTHROPIC_BASE_URL": "https://llapi.org/v1",
    "ANTHROPIC_AUTH_TOKEN": "sk-你的灵链云密钥",
    "ANTHROPIC_MODEL": "claude-sonnet-4-5"
  }
}

说明：模型名以灵链云控制台「可用模型」为准，可先请求 GET /v1/models 查看支持列表。

临时方式（仅当前终端）

macOS / Linux（bash / zsh）：

export ANTHROPIC_BASE_URL="https://llapi.org/v1"
export ANTHROPIC_AUTH_TOKEN="sk-你的灵链云密钥"

Windows PowerShell：

$env:ANTHROPIC_BASE_URL = "https://llapi.org/v1"
$env:ANTHROPIC_AUTH_TOKEN = "sk-你的灵链云密钥"

四、第三步：验证连通性

保存配置后，重新打开终端并启动 Claude Code：

claude

输入任意问题，例如 /status 查看当前账户与模型状态。能正常返回即表示接入成功。

也可以先不带交互、直接测一次 API 连通：

curl https://llapi.org/v1/messages \
  -H "x-api-key: sk-你的灵链云密钥" \
  -H "anthropic-version: 2023-06-01" \
  -d '{"model":"claude-sonnet-4-5","max_tokens":64,"messages":[{"role":"user","content":"ping"}]}'

提示：部分中转站同时提供 OpenAI 兼容与 Anthropic 原生两种协议，若你的客户端走 /v1/chat/completions，见 OpenAI 兼容接入说明。

五、常见报错与排查

现象原因解决办法
401 / authentication_error API Key 错误或未复制完整 在控制台重新生成 Key，确认前缀 sk- 完整写入
402 / insufficient balance 账户余额不足 前往会员中心充值后重试
404 model not found 模型名与网关不一致 调用 /v1/models 查看可用模型名后替换
请求超时 / 连接失败 本地网络到网关不通 检查是否配置了冲突的代理；确认域名可直连
报错里地址仍是 api.anthropic.com 环境变量未生效 确认写入 settings.json 的 env 块并重启终端

六、常见问题 FAQ

用中转站跑 Claude Code 安全吗？

灵链云走网关统一鉴权与用量记录，请求不绑定你的 Claude 个人账号，也就不会因为中转调用影响你个人账号。 建议不要把敏感密钥与生产代码明文放在一起，Key 仅限本人使用。

和官方 Claude API 有什么区别？

核心差异在接入方式与付费：官方需要海外网络 + 外币卡；灵链云提供国内直连地址与支付宝 / 微信充值， 并统一管理多个模型。官方对数据合规要求极严的场景仍是首选，灵链云适合国内团队、个人开发者的日常开发与工具调用。

充值余额可以退款吗？

支持按实际消费结算；建议小额多次充值。具体退款与开票规则以控制台「会员中心」说明为准。
