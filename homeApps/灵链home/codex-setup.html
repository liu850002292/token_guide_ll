Codex CLI 配置教程：3 分钟接入灵链云

Codex CLI 是 OpenAI 的命令行 AI 编程工具，底层走 OpenAI 兼容协议。 因为协议标准，接第三方网关非常容易：改一行 base_url、填一个 env_key 即可。 本教程带你用灵链云跑通 Codex，国内直连、按量计费、余额透明。

核心要点：
  • Codex 通过 ~/.codex/config.toml 配置自定义模型提供方（provider）；
  • 新增一个指向 https://llapi.org/v1 的 provider，再切换到该模型即可；
  • 全程不需要修改 Codex 本体，也不影响其它项目。

一、接入前提

  • 已安装 Codex CLI，并能在终端启动 codex 命令；
  • 有 灵链云账号 并已创建 API Key、账户有余额；
  • 终端可直连 https://llapi.org/v1。

还没有账号？先到 灵链云注册页 注册，新用户送体验额度。

二、第一步：注册并创建 API Key

登录 llapi.org 后，在「会员中心」完成小额充值（支持支付宝 / 微信）， 然后在控制台「API Key」新建密钥，密钥形如 sk-xxxxxxxx，创建后立即复制保存。

三、第二步：修改 Codex config.toml

编辑 ~/.codex/config.toml（Windows 为 %USERPROFILE%\.codex\config.toml），加入以下内容：

# 灵链云 OpenAI 兼容 provider
[model_providers.llapi]
name = "灵链云"
base_url = "https://llapi.org/v1"
env_key = "LLAPI_API_KEY"
wire_api = "chat"

# 切换到灵链云提供的模型（模型名以控制台为准）
model = "gpt-5"
model_provider = "llapi"

然后在终端设置环境变量（内容为你刚创建的灵链云 Key）：

macOS / Linux：

export LLAPI_API_KEY="sk-你的灵链云密钥"

Windows PowerShell：

$env:LLAPI_API_KEY = "sk-你的灵链云密钥"

说明：env_key 名称可自定义，只要与上面的环境变量一致即可；wire_api = "chat" 表示走 /v1/chat/completions 协议。模型名以 灵链云文档 的可用模型列表为准。

四、第三步：验证 Codex 连通

保存配置后，在新终端里启动 Codex：

codex

输入一个简单问题，例如「用 Python 写一个 hello world」。能正常回答即接入成功。

也可以用 curl 直接验证灵链云的 OpenAI 兼容接口（返回内容即连通）：

curl https://llapi.org/v1/chat/completions \
  -H "Authorization: Bearer sk-你的灵链云密钥" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5","messages":[{"role":"user","content":"ping"}]}'

五、常见报错与排查

现象原因解决办法
401 unauthorized 环境变量未设置或 Key 错误 确认 LLAPI_API_KEY 已导出且 Key 完整
invalid model / 模型不存在 模型名与网关不一致 查看灵链云控制台可用模型，替换 config.toml 中的 model
402 insufficient balance 余额不足 会员中心充值后重试
连接超时 本地网络到网关不通 检查是否有冲突代理，确认可直连 llapi.org

六、常见问题 FAQ

Codex 一定要求 OpenAI 官方账号吗？

不一定。Codex 支持自定义 provider，只要对方提供 OpenAI 兼容的 /v1/chat/completions 接口， 就能用灵链云这样的中转站接入，不要求 OpenAI 官方订阅。

走中转站和官方 API 有区别吗？

协议完全一致，主要是接入入口与付费方式不同：灵链云提供国内直连地址、支持支付宝 / 微信充值、 统一的用量统计与余额管理。对国内团队和个人开发者是更省事的接入方式。

这个配置会不会影响 Codex 其它功能？

不会。自定义 provider 是 Codex 官方支持的配置项，只影响模型调用来源，不影响命令行工具本身的功能。
