一、什么是 OpenAI 兼容 API

OpenAI 兼容（OpenAI-Compatible）指接口请求与响应格式与 OpenAI 官方 /v1/chat/completions 保持一致，包含 model、messages、 stream 等字段。凡是按这个协议写的 SDK、客户端、脚本，都可以通过「换地址 + 换 Key」 的方式接入灵链云聚合的其它模型，业务代码保持不变。

灵链云的统一接入地址：

Base URL: https://llapi.org/v1

三、Python / Node / curl 调用示例

Python（OpenAI SDK）

from openai import OpenAI

client = OpenAI(
    api_key="sk-你的灵链云密钥",
    base_url="https://llapi.org/v1",
)

resp = client.chat.completions.create(
    model="claude-sonnet-4-5",  # 模型名以控制台为准，可自由切换
    messages=[{"role": "user", "content": "你好"}],
)
print(resp.choices[0].message.content)

Node.js（OpenAI SDK）

import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "sk-你的灵链云密钥",
  baseURL: "https://llapi.org/v1",
});

const resp = await client.chat.completions.create({
  model: "gpt-5",
  messages: [{ role: "user", content: "你好" }],
});
console.log(resp.choices[0].message.content);

curl

curl https://llapi.org/v1/chat/completions \
  -H "Authorization: Bearer sk-你的灵链云密钥" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5","messages":[{"role":"user","content":"ping"}]}'

六、常见问题 FAQ

换 Base URL 需要改多少代码？

通常只需改客户端或 SDK 初始化处的 Base URL 与 API Key。标准 OpenAI 兼容场景下，业务代码完全不用动。

一个 Key 能同时用多个模型吗？

可以。密钥与用量统一，调用时通过 model 参数切换，无需为每个模型单独申请 Key。

怎么确认模型没被「偷换」？

灵链云强调渠道与计费透明，控制台可查看每次调用的模型、Token 与费用明细。建议新用户先用赠送额度 小量测试，跑通后再按需充值。
